# Ressourcen

Ein kuratiertes Verzeichnis dessen, was ein Steem-Entwickler im Alltag benötigt — die Anleitungen dieser Website, die offiziellen Client-Bibliotheken und die Tools rund um die Chain. Externe Links wurden zum Zeitpunkt der Veröffentlichung auf Funktionsfähigkeit geprüft.

## Der Einstieg

- **[Schnellstart](/quickstart/)** — wählen Sie eine Client-Bibliothek und machen Sie Ihren ersten API-Aufruf; die Seite enthält außerdem die von der Community gepflegte Liste der [öffentlichen RPC-Knoten](/quickstart/).
- **[Tutorials](/tutorials/)** — praxisnahe Kapitel zu [steem-js](/tutorials/steem-js/) und [steemgosdk](/tutorials/steemgosdk/), übertragen aus der eigenen Dokumentation der Bibliotheken.
- **[API-Referenz](/api/)** — jede JSON-RPC-API der Chain, eine Seite pro Methode.

## Offizielle Client-Bibliotheken

| Bibliothek | Sprache | Tutorials auf dieser Website |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [steem-js-Tutorials](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [steemgosdk-Tutorials](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python (enthält die CLI `steempy`) | — |

Die Bibliotheksbeschreibungen folgen den jeweiligen READMEs der Repositories; steemgosdk verweist dort auf aktive Entwicklung.

## Offizielle Dokumentation

- [steem-Core-Repository](https://github.com/steemit/steem) — die Implementierung der Blockchain, einschließlich der Dokumentation auf Protokollebene.
- [steem.io](https://steem.io) — die offizielle Website des Projekts (Whitepaper, allgemeine Informationen).

## Tools und Explorer

- [steemitwallet.com](https://steemitwallet.com) — die offizielle Web-Wallet.
- [steemdb.io](https://steemdb.io) — Block-Explorer: Blöcke, Transaktionen und Kontoverlauf.
- [steemworld.org](https://steemworld.org) — Community-Werkzeugkasten für Konten (Votes, Delegationen, Mentions und mehr).
