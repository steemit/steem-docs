# Introduction

Ce site est la documentation développeur de la blockchain Steem. Son cœur est une référence JSON-RPC API complète : chaque méthode API possède sa propre page, générée à la construction à partir d’une unique source de vérité YAML — adressable individuellement, entièrement interrogeable et disponible en huit langues.

## Comment le site est organisé

La barre latérale reflète la structure réelle du site :

- **Référence API** — la référence JSON-RPC de [condenser_api](/api/condenser_api/) et des espaces de noms des API AppBase (account history, follow, market history, witness, etc.), chaque méthode étant documentée sur sa propre page. Un [index des API](/api/) généré liste toutes les API et leurs méthodes.
- **Guides** — la documentation orientée tâches : l’[Introduction](/introduction/) (cette page), le guide [Démarrage rapide](/quickstart/) avec la liste communautaire des [nœuds publics](/quickstart/), le [Glossaire](/glossary/) des termes Steem, plus les sections [Ressources](/resources/) et [Testnet](/testnet/) en préparation.
- **Services** — la documentation des services autour de la chaîne : le service d’images [ImageHoster](/services/imagehoster.html), [Jussi](/services/jussi.html) (documentation en préparation) et [Steem DAO](/services/steem-dao.html) (à organiser).

## Langues

La référence API est disponible en huit langues — English, 简体中文, Русский, Français, Deutsch, Italiano, Español, 한국어. Basculez entre elles avec le menu des langues dans la barre de navigation en haut. Dans la section Guides, seules Introduction et Démarrage rapide sont traduites en français pour l’instant ; les autres pages sont en anglais.

## Ressources externes

- [github.com/steemit](https://github.com/steemit) — l’organisation GitHub de Steem, foyer du logiciel de nœud de la blockchain ([steemit/steem](https://github.com/steemit/steem)) et des dépôts apparentés.
- [steemit.com FAQ](https://steemit.com/faq.html) — réponses aux questions courantes sur Steem, ses tokens et sa gouvernance.
- [steem-docs](https://github.com/steemit/steem-docs) — la source de ce site. Si vous trouvez une erreur ou un manque, ouvrez une issue ou soumettez une pull request.
