# Resources

A curated directory of what a Steem developer needs day to day — this site's guides, the official client libraries, and the tools around the chain. External links were verified working at the time of publication.

## Start here

- **[Quickstart](/quickstart/)** — pick a client library and make your first API call; also hosts the community-maintained [public RPC node](/quickstart/) list.
- **[Tutorials](/tutorials/)** — hands-on chapters for [steem-js](/tutorials/steem-js/) and [steemgosdk](/tutorials/steemgosdk/), migrated from the libraries' own documentation.
- **[API Reference](/api/)** — every JSON-RPC API of the chain, one page per method.

## Official client libraries

| Library | Language | Tutorials on this site |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [steem-js tutorials](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [steemgosdk tutorials](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python (includes the `steempy` CLI) | — |

Library summaries follow the repositories' own READMEs; steemgosdk notes active development there.

## Official documentation

- [steem core repository](https://github.com/steemit/steem) — the blockchain implementation, including protocol-level documentation.
- [steem.io](https://steem.io) — the project's official website (whitepaper, general information).

## Tools and explorers

- [steemitwallet.com](https://steemitwallet.com) — the official web wallet.
- [steemdb.io](https://steemdb.io) — block explorer: blocks, transactions, and account history.
- [steemworld.org](https://steemworld.org) — community account toolbox (votes, delegations, mentions, and more).

## Community

- [Steem Discord](https://discord.gg/QTuZr5F) — developer and community chat.
