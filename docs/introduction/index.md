# Introduction

This site is the developer documentation for the Steem blockchain. Its core is a complete JSON-RPC API reference: every API method has its own page, generated at build time from a single YAML source of truth — individually addressable, fully searchable, and available in eight languages.

## How the site is organized

The sidebar mirrors the site's actual structure:

- **API Reference** — the JSON-RPC reference for the [condenser_api](/api/condenser_api/) and the appbase API namespaces (account history, follow, market history, witness, and more), with every method documented on its own page. A generated [API index](/api/) lists all APIs and their methods.
- **Guides** — task-oriented documentation: the [Introduction](/introduction/) (this page), the [Quickstart](/quickstart/) guide with the community [public nodes](/quickstart/) list, the [Glossary](/glossary/) of Steem terms, plus [Resources](/resources/) and [Testnet](/testnet/) sections that are being prepared.
- **Services** — documentation for the services around the chain: the [ImageHoster](/services/imagehoster/) image service, [Jussi](/services/jussi/) (documentation being prepared) and [Steem DAO](/services/steem-dao/) (to be organized).

## Languages

The API reference is available in eight languages — English, 简体中文, Русский, Français, Deutsch, Italiano, Español, 한국어. Switch between them with the language menu in the top navigation bar. The Guides section is English-only for now.

## External resources

- [github.com/steemit](https://github.com/steemit) — the Steem GitHub organization, home of the blockchain node software ([steemit/steem](https://github.com/steemit/steem)) and related repositories.
- [steemit.com FAQ](https://steemit.com/faq.html) — answers to common questions about Steem, its tokens, and its governance.
- [steem-docs](https://github.com/steemit/steem-docs) — the source of this site. If you find an error or a gap, open an issue or submit a pull request.
