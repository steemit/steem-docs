# Risorse

Una directory curata di ciò che uno sviluppatore Steem necessita giorno per giorno — le guide di questo sito, le librerie client ufficiali e gli strumenti attorno alla catena. I link esterni sono stati verificati come funzionanti al momento della pubblicazione.

## Inizia da qui

- **[Avvio rapido](/quickstart/)** — scegli una libreria client ed effettua la tua prima chiamata API; la pagina ospita anche l’elenco community dei [nodi RPC pubblici](/quickstart/).
- **[Tutorial](/tutorials/)** — capitoli pratici su [steem-js](/tutorials/steem-js/) e [steemgosdk](/tutorials/steemgosdk/), migrati dalla documentazione delle stesse librerie.
- **[Riferimento API](/api/)** — ogni API JSON-RPC della catena, una pagina per metodo.

## Librerie client ufficiali

| Libreria | Linguaggio | Tutorial su questo sito |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [tutorial steem-js](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [tutorial steemgosdk](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python (include la CLI `steempy`) | — |

I riassunti delle librerie seguono i README dei rispettivi repository; steemgosdk vi segnala lo sviluppo attivo.

## Documentazione ufficiale

- [repository del core steem](https://github.com/steemit/steem) — l’implementazione della blockchain, inclusa la documentazione a livello di protocollo.
- [steem.io](https://steem.io) — il sito ufficiale del progetto (whitepaper, informazioni generali).

## Strumenti ed esploratori

- [steemitwallet.com](https://steemitwallet.com) — il wallet web ufficiale.
- [steemdb.io](https://steemdb.io) — esploratore di blocchi: blocchi, transazioni e cronologia degli account.
- [steemworld.org](https://steemworld.org) — toolbox community per gli account (voti, delegazioni, menzioni e altro).

## Community

- [Steem Discord](https://discord.gg/QTuZr5F) — la chat per sviluppatori e community.
