# Introduzione

Questo sito è la documentazione per sviluppatori della blockchain Steem. Il suo nucleo è un riferimento JSON-RPC API completo: ogni metodo API ha una propria pagina, generata in fase di build da un’unica fonte di verità YAML — indirizzabile singolarmente, interamente ricercabile e disponibile in otto lingue.

## Come è organizzato il sito

La barra laterale rispecchia la struttura reale del sito:

- **Riferimento API** — il riferimento JSON-RPC per [condenser_api](/api/condenser_api/) e i namespace delle API AppBase (account history, follow, market history, witness e altri), con ogni metodo documentato sulla propria pagina. Un [indice delle API](/api/) generato elenca tutte le API e i loro metodi.
- **Guide** — documentazione orientata alle attività: l’[Introduzione](/introduction/) (questa pagina), la guida [Avvio rapido](/quickstart/) con l’elenco community dei [nodi pubblici](/quickstart/), il [Glossario](/glossary/) dei termini Steem, più la directory [Risorse](/resources/) (la sezione [Testnet](/testnet/) è ancora in preparazione).
- **Servizi** — documentazione dei servizi attorno alla catena: il servizio immagini [ImageHoster](/services/imagehoster.html), [Jussi](/services/jussi.html) (documentazione in preparazione) e [Steem DAO](/services/steem-dao.html).

## Lingue

Il riferimento API è disponibile in otto lingue — English, 简体中文, Русский, Français, Deutsch, Italiano, Español, 한국어. Passa da una all’altra con il menu delle lingue nella barra di navigazione in alto. Nella sezione Guide, per ora solo Introduzione e Avvio rapido sono disponibili in italiano; le altre pagine sono in inglese.

## Risorse esterne

- [github.com/steemit](https://github.com/steemit) — l’organizzazione GitHub di Steem, casa del software dei nodi della blockchain ([steemit/steem](https://github.com/steemit/steem)) e dei repository correlati.
- [steemit.com FAQ](https://steemit.com/faq.html) — risposte alle domande comuni su Steem, i suoi token e la sua governance.
- [steem-docs](https://github.com/steemit/steem-docs) — la fonte di questo sito. Se trovi un errore o una lacuna, apri una issue o invia una pull request.
