# Ресурсы

Подобранный каталог того, что разработчику Steem нужно изо дня в день, — руководства этого сайта, официальные клиентские библиотеки и инструменты вокруг цепочки. Внешние ссылки были проверены на работоспособность на момент публикации.

## С чего начать

- **[Быстрый старт](/quickstart/)** — выберите клиентскую библиотеку и выполните свой первый вызов API; там же ведётся поддерживаемый сообществом список [публичных RPC-узлов](/quickstart/).
- **[Обучающие материалы](/tutorials/)** — практические главы по [steem-js](/tutorials/steem-js/) и [steemgosdk](/tutorials/steemgosdk/), перенесённые из собственной документации этих библиотек.
- **[Справочник API](/api/)** — каждый JSON-RPC API цепочки, одна страница на метод.

## Официальные клиентские библиотеки

| Библиотека | Язык | Обучающие материалы на сайте |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [обучающие материалы steem-js](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [обучающие материалы steemgosdk](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python (включая CLI `steempy`) | — |

Описания библиотек следуют собственным README репозиториев; в README steemgosdk отмечена активная разработка.

## Официальная документация

- [репозиторий ядра steem](https://github.com/steemit/steem) — реализация блокчейна, включая документацию уровня протокола.
- [steem.io](https://steem.io) — официальный сайт проекта (белая книга, общая информация).

## Инструменты и обозреватели

- [steemitwallet.com](https://steemitwallet.com) — официальный веб-кошелёк.
- [steemdb.io](https://steemdb.io) — обозреватель блоков (block explorer): блоки, транзакции и история аккаунтов.
- [steemworld.org](https://steemworld.org) — набор инструментов для аккаунтов от сообщества (голоса, делегирование, упоминания и другое).

## Сообщество

- [Steem Discord](https://discord.gg/QTuZr5F) — чат разработчиков и сообщества.
