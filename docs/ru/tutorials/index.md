# Обучающие материалы

В этом разделе собраны практические примеры использования двух официальных клиентских библиотек Steem (client library). Все примеры перенесены из документации самих библиотек, и демонстрации можно запускать через публичный узел (node), такой как `https://api.steemit.com`.

## Библиотеки

| Библиотека | Язык | Пакет / модуль | Репозиторий |
|---------|----------|------------------|------------|
| steem-js | JavaScript / TypeScript | npm-пакет `@steemit/steem-js` 1.2.4 | [steemit/steem-js](https://github.com/steemit/steem-js) |
| steemgosdk | Go | Go-модуль `github.com/steemit/steemgosdk` | [steemit/steemgosdk](https://github.com/steemit/steemgosdk) |

Обе библиотеки обращаются к тому же JSON-RPC API, который метод за методом документирует сгенерированный [справочник API](/ru/api/). Используйте руководства, чтобы освоить клиентские паттерны; используйте справочник API, чтобы узнать детали каждого метода «на проводе».

## Страницы steem-js

- [Быстрый старт](/ru/tutorials/steem-js/) - установка, использование в браузере, конфигурация (`config.set`, `api.setUrl`, `setOptions`, несколько экземпляров API), обзор JSON-RPC, маршрутизация API, сквозные примеры использования, поддержка TypeScript и обработка ошибок.
- [Чтение данных цепочки](/ru/tutorials/steem-js/read-api.html) - все вспомогательные методы чтения: теги (tag), блог и обсуждения, блоки (block), глобальные свойства, аккаунты, рынок, голоса, контент, свидетели (witness), а также вспомогательные методы login/follow и офлайн-утилиты аутентификации, форматирования и utils.
- [Операции широковещания](/ru/tutorials/steem-js/broadcast.html) - полный каталог операций `steem.broadcast`, паттерны с promise/callback, мультисиг и бинарная сериализация транзакций (transaction).
- [Подписанные вызовы и проверка подписи](/ru/tutorials/steem-js/signed-calls.html) - аутентифицированные запросы `signedCall` и набор инструментов проверки подписи с полными примерами-руководствами.
- [Миграция тестов rpc-auth](/ru/tutorials/steem-js/rpc-auth-migration.html) - как набор тестов `rpc-auth` был перенесён в steem-js.

## Страницы steemgosdk

- [Быстрый старт](/ru/tutorials/steemgosdk/) - настройка клиента, примеры API чтения цепочки, примеры генерации ключей для аутентификации и примеры подписания Steem URI.
- [Операции широковещания](/ru/tutorials/steemgosdk/broadcast.html) - голосования (vote), переводы (transfer), комментарии, опции комментариев с бенефициарами (beneficiary), транзакции с несколькими операциями и широковещание custom_json, а также полные сквозные примеры.
- [SignedCall API](/ru/tutorials/steemgosdk/signed-call.html) - аутентифицированные JSON-RPC вызовы из Go, совместимые с подписанными вызовами steem-js.

## Примечания

- Пока руководства доступны только на английском, как и раздел Guides.
- В примерах фигурируют широко известные тестовые ключи из документации самих библиотек; никогда не используйте их в продакшене — генерируйте собственные ключи, как показано в примерах аутентификации.
