# Введение

Этот сайт — документация разработчика блокчейна Steem. Её ядро — полный справочник JSON-RPC API: у каждого метода API есть собственная страница, генерируемая на этапе сборки из единого YAML-источника истины — с прямой адресацией, полнотекстовым поиском и доступностью на восьми языках.

## Как устроен сайт

Боковая панель отражает реальную структуру сайта:

- **Справочник API** — справочник JSON-RPC для [condenser_api](/api/condenser_api/) и пространств имён API AppBase (account history, follow, market history, witness и другие), где каждый метод задокументирован на своей странице. Автоматически генерируемый [индекс API](/api/) перечисляет все API и их методы.
- **Руководства** — документация, ориентированная на задачи: [Введение](/introduction/) (эта страница), руководство [Быстрый старт](/quickstart/) со списком поддерживаемых сообществом [публичных узлов](/quickstart/), [глоссарий](/glossary/) терминов Steem, а также готовящиеся разделы [Ресурсы](/resources/) и [Тестовая сеть](/testnet/).
- **Сервисы** — документация сервисов вокруг цепочки: сервис изображений [ImageHoster](/services/imagehoster.html), [Jussi](/services/jussi.html) (документация готовится) и [Steem DAO](/services/steem-dao.html) (в процессе организации).

## Языки

Справочник API доступен на восьми языках — English, 简体中文, Русский, Français, Deutsch, Italiano, Español, 한국어. Переключайтесь между ними через меню языков в верхней навигационной панели. Из раздела «Руководства» на русский пока переведены только Введение и Быстрый старт; остальные страницы — на английском.
