# 서비스

Steem 블록체인을 뒷받침하는 서비스들 — 각각의 역할과 사용 방법.

- **[ImageHoster](/services/imagehoster)** — Steem 애플리케이션을 위한 이미지 호스팅, 프록시, 아바타 제공. 전체 HTTP 사용 참조 포함.
- **[Jussi](/services/jussi)** — Steem API 노드 앞단의 캐싱 리버스 프록시 (문서 재정리 중).
- **[Steem DAO](/services/steem-dao)** — Steem 프로포절 시스템(Steem Proposal System) 뒤의 온체인 프로포절(proposal) 펀딩 (콘텐츠 준비 중).
