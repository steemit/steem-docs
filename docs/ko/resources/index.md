# 리소스

Steem 개발자가 매일 필요로 하는 것들을 모아 둔 선별 디렉터리입니다 — 이 사이트의 가이드, 공식 클라이언트 라이브러리, 그리고 체인 주변의 도구들. 외부 링크는 게시 시점에 정상 작동을 확인했습니다.

## 여기서 시작하기

- **[빠른 시작](/quickstart/)** — 클라이언트 라이브러리를 골라 첫 API 호출을 해 보세요. 이 페이지에는 커뮤니티가 관리하는 [퍼블릭 RPC 노드](/quickstart/) 목록도 있습니다.
- **[튜토리얼](/tutorials/)** — [steem-js](/tutorials/steem-js/)와 [steemgosdk](/tutorials/steemgosdk/)의 실습 챕터로, 각 라이브러리의 자체 문서에서 옮겨 왔습니다.
- **[API 레퍼런스](/api/)** — 체인의 모든 JSON-RPC API를 메서드별 전용 페이지로 정리합니다.

## 공식 클라이언트 라이브러리

| 라이브러리 | 언어 | 이 사이트의 튜토리얼 |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [steem-js 튜토리얼](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [steemgosdk 튜토리얼](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python (`steempy` CLI 포함) | — |

라이브러리 소개는 각 저장소의 README를 따랐습니다. steemgosdk는 그곳에서 활발한 개발이 진행 중임을 밝히고 있습니다.

## 공식 문서

- [steem 코어 저장소](https://github.com/steemit/steem) — 블록체인 구현체로, 프로토콜 수준의 문서를 포함합니다.
- [steem.io](https://steem.io) — 프로젝트 공식 웹사이트(백서, 일반 정보).

## 도구와 익스플로러

- [steemitwallet.com](https://steemitwallet.com) — 공식 웹 지갑.
- [steemdb.io](https://steemdb.io) — 블록 익스플로러: 블록, 트랜잭션, 계정 기록.
- [steemworld.org](https://steemworld.org) — 커뮤니티 계정 툴박스(투표, 위임, 멘션 등).

## 커뮤니티

- [Steem Discord](https://discord.gg/QTuZr5F) — 개발자와 커뮤니티를 위한 채팅.
