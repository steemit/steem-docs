# Recursos

Un directorio seleccionado de lo que un desarrollador de Steem necesita en el día a día — las guías de este sitio, las bibliotecas cliente oficiales y las herramientas en torno a la cadena. Los enlaces externos se verificaron como funcionales en el momento de la publicación.

## Empieza aquí

- **[Inicio rápido](/quickstart/)** — elige una biblioteca cliente y realiza tu primera llamada a la API; la página también aloja la lista comunitaria de [nodos RPC públicos](/quickstart/).
- **[Tutoriales](/tutorials/)** — capítulos prácticos sobre [steem-js](/tutorials/steem-js/) y [steemgosdk](/tutorials/steemgosdk/), migrados de la documentación propia de las bibliotecas.
- **[Referencia de API](/api/)** — cada API JSON-RPC de la cadena, una página por método.

## Bibliotecas cliente oficiales

| Biblioteca | Lenguaje | Tutoriales en este sitio |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [tutoriales de steem-js](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [tutoriales de steemgosdk](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python (incluye la CLI `steempy`) | — |

Los resúmenes de las bibliotecas siguen los README de los propios repositorios; steemgosdk indica allí un desarrollo activo.

## Documentación oficial

- [repositorio del core de steem](https://github.com/steemit/steem) — la implementación de la blockchain, incluida la documentación a nivel de protocolo.
- [steem.io](https://steem.io) — el sitio web oficial del proyecto (whitepaper, información general).

## Herramientas y exploradores

- [steemitwallet.com](https://steemitwallet.com) — la billetera web oficial.
- [steemdb.io](https://steemdb.io) — explorador de bloques: bloques, transacciones e historial de cuentas.
- [steemworld.org](https://steemworld.org) — caja de herramientas comunitaria para cuentas (votos, delegaciones, menciones y más).

## Comunidad

- [Steem Discord](https://discord.gg/QTuZr5F) — el chat de desarrolladores y comunidad.
