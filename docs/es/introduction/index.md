# Introducción

Este sitio es la documentación para desarrolladores de la blockchain de Steem. Su núcleo es una referencia completa de la API JSON-RPC: cada método de la API tiene su propia página, generada en tiempo de compilación a partir de una única fuente de verdad en YAML — direccionable individualmente, totalmente buscable y disponible en ocho idiomas.

## Cómo está organizado el sitio

La barra lateral refleja la estructura real del sitio:

- **Referencia de API** — la referencia JSON-RPC de [condenser_api](/api/condenser_api/) y de los espacios de nombres de las API de AppBase (account history, follow, market history, witness y más), con cada método documentado en su propia página. Un [índice de API](/api/) generado enumera todas las API y sus métodos.
- **Guías** — documentación orientada a tareas: la [Introducción](/introduction/) (esta página), la guía de [Inicio rápido](/quickstart/) con la lista comunitaria de [nodos públicos](/quickstart/), el [Glosario](/glossary/) de términos de Steem, además del directorio [Recursos](/resources/) (la sección [Testnet](/testnet/) sigue en preparación).
- **Servicios** — documentación de los servicios en torno a la cadena: el servicio de imágenes [ImageHoster](/services/imagehoster.html), [Jussi](/services/jussi.html) (documentación en preparación) y [Steem DAO](/services/steem-dao.html).

## Idiomas

La referencia de la API está disponible en ocho idiomas — English, 简体中文, Русский, Français, Deutsch, Italiano, Español, 한국어. Cambie entre ellos con el menú de idiomas de la barra de navegación superior. De la sección Guías, por ahora solo Introducción e Inicio rápido están disponibles en español; el resto de páginas está en inglés.

## Recursos externos

- [github.com/steemit](https://github.com/steemit) — la organización de Steem en GitHub, hogar del software de nodos de la blockchain ([steemit/steem](https://github.com/steemit/steem)) y de repositorios relacionados.
- [steemit.com FAQ](https://steemit.com/faq.html) — respuestas a preguntas frecuentes sobre Steem, sus tokens y su gobernanza.
- [steem-docs](https://github.com/steemit/steem-docs) — el código fuente de este sitio. Si encuentra un error o un vacío, abra un issue o envíe un pull request.
