# 资源

这里是一份精选目录，汇总 Steem 开发者日常所需的资源——本站的指南、官方客户端库（client library）以及链周边的工具。外部链接在发布时均已验证可用。

## 从这里开始

- **[快速开始](/quickstart/)** —— 选择一个客户端库，完成你的第一次 API 调用；该页还收录社区（community）维护的[公共 RPC 节点](/quickstart/)列表。
- **[教程](/tutorials/)** —— [steem-js](/tutorials/steem-js/) 与 [steemgosdk](/tutorials/steemgosdk/) 的动手章节，迁移自各库自身的文档。
- **[API 参考](/api/)** —— 链上每一个 JSON-RPC API，每个方法一页。

## 官方客户端库

| 库 | 语言 | 本站教程 |
|---|---|---|
| [steem-js](https://github.com/steemit/steem-js) (`@steemit/steem-js`) | JavaScript / TypeScript | [steem-js 教程](/tutorials/steem-js/) |
| [steemgosdk](https://github.com/steemit/steemgosdk) | Go | [steemgosdk 教程](/tutorials/steemgosdk/) |
| [steem-python](https://github.com/steemit/steem-python) | Python（含 `steempy` CLI） | — |

各库简介沿用其仓库自带的 README；steemgosdk 在其中注明正在积极开发中。

## 官方文档

- [steem 核心仓库](https://github.com/steemit/steem) —— 区块链的实现，包括协议层文档。
- [steem.io](https://steem.io) —— 项目官方网站（白皮书与一般信息）。

## 工具与区块浏览器

- [steemitwallet.com](https://steemitwallet.com) —— 官方网页钱包。
- [steemdb.io](https://steemdb.io) —— 区块浏览器（block explorer）：区块、交易与账户历史。
- [steemworld.org](https://steemworld.org) —— 社区账户工具箱（投票、代理、提及等）。
